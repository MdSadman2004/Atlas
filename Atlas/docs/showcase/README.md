# Showcase media

These are actual existing project captures, not generated mockups. This presentation update did not re-test applications.

- **Grid Protocol:** real WebGL canvas recordings from the local prototype. Driving and flight were staged with scripted inputs and showcase cameras. Each MP4 is a 10-second excerpt, 1280×720 at 30 fps; GIF previews are 6 seconds at 12 fps. Those are encoding settings, not game-performance claims. No source geometry was changed for these clips. HUD is absent because the source recording was canvas-only. No licensed soundtrack is included. The captured local build may differ from the repository snapshot.
- **Sadman's Parable:** existing WebGL environment screenshots with the original narrative overlay. They demonstrate scenes, not a continuous playthrough; the same dialogue can remain visible across scene captures.
- **Diecast Dhaka:** existing desktop and mobile prototype captures. Inventory, stock and prices are demonstrations. Cars are illustrative 3D silhouettes, not exact replicas or authenticated product photos.
- **Atlas:** historical Android goal-configuration capture. The goal reports zero runs and last never; this is not evidence of successful background automation. The editorial spread frames the intact screenshot without inventing UI.

All existing project credits, affiliation notices and license terms remain in the relevant repository READMEs. Media inclusion does not add a repository-wide license grant.
